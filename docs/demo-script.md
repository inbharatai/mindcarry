# Demo script

1. Open MindCarry in demo mode.
2. Create Aarav, age 7, interest `dinosaurs`, with camera permission optional and raw media disabled.
3. Unlock Aarav's Learner Memory.
4. Start the maths lesson.
5. Answer `11` to `7 + 5` and explain that you counted incorrectly.
6. MindCarry records an off-by-one misconception and gives a dinosaur/counting-on intervention.
7. Answer the next question correctly.
8. Answer the transfer question correctly.
9. Show the completion mastery and dashboard memories.
10. Close/reopen and unlock to show persistence.
11. Export `Aarav.childmind`.
12. Import it into another installation and unlock with the same passphrase.
13. Open Settings, add a Gemini test key and test the connection.
