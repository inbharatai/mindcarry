# Privacy model

- Permanent learner memory is local.
- Gemini is optional and used for generated explanations.
- Only limited lesson context is sent to Gemini.
- The API key is stored separately with Electron safeStorage.
- Camera use is optional and disabled by default.
- Raw camera video and audio are not stored in the alpha.
- The camera feature currently computes local movement intensity only.
- Behavioural signals are temporary teaching cues, not diagnoses.
- Parents can export the encrypted learner package and choose where to keep it.
